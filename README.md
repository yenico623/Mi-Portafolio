## 🎯 ¿Qué es?

Sitio web personal donde presento mi perfil profesional, habilidades técnicas y proyectos desarrollados durante mi proceso de formación como desarrolladora backend.

## 🛠️ Tecnologías usadas

- HTML5 semántico
- CSS3 (Flexbox + Grid)
- CSS Variables
- Diseño responsivo (mobile-first)

## 🚀 Cómo verlo localmente

```bash
git clone https://github.com/yenico623/Mi-Portafolio.git
cd Mi-Portafolio
```
Abre `index.html` en tu navegador (recomendado: con la extensión Live Server de VS Code).

## 📌 Secciones

- Hero / Presentación
- Servicios
- Collage (CSS Grid)
- Proyectos
- Sobre Mí
- Formulario de Contacto

## 🧠 Retos y aprendizajes

Construir este portafolio me permitió aplicar Flexbox y CSS Grid en un mismo proyecto para lograr layouts distintos (como el collage visual), y reforzar buenas prácticas de HTML5 semántico y accesibilidad.
